# AI Operating Framework

Programa **AI Adoption** da área de Desenvolvimento da Overlabs.

Reúne estratégia, governança, frentes de execução, artefatos, pesquisa e playbooks
da adoção de IA na área. A primeira frente é o **Kairós**, que automatiza a esteira
de projetos de MP01 a MP10.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `01-programa/` | Estratégia, roadmap, equipe e governança do programa |
| `02-frentes/` | Frentes de execução (hoje: `kairos/`) |
| `03-artefatos/` | Apresentações, diagramas e documentos |
| `04-pesquisa/` | Pesquisas e referências |
| `05-playbooks/` | Playbooks operacionais |
| `.claude/skills/` | Skills do Claude Code |
